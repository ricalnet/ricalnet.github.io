FAQ

Your questions, answered

Everything you need to know about building your own privacy‑first, open‑source stack.

What exactly does RICALNET provide?

RICALNET offers a public repository with ready‑to‑use Podman Compose configs for 25+ privacy services — all open‑source and self‑hostable. No proprietary lock‑in, no recurring fees.

Is this only for tech‑savvy people?

Not at all. The repo is designed for anyone comfortable with the command line. Docs include detailed guides, one‑command deployment scripts, and an interactive menu. For enterprises, consulting and managed deployment are available. For homelabbers, it's a practical, educational project.

How do you ensure zero‑trust security?

The architecture includes network segmentation, strict access controls, and regular updates. Monitoring and alerting detect anomalies. You have full control to harden as needed.

How much does it cost to run?

Very little. You pay only for hardware (or VPS), electricity, and bandwidth. Most services run on a $5–$10/month VPS for personal use, or a Raspberry Pi for near‑zero recurring cost. No per‑user licenses, no egress fees, no minimum spend.

How do I get started?

Clone the repo, run the setup script, and you're up in minutes. Step‑by‑step guides cover everything from homelab to internal enterprise. For enterprise or activist deployments, RICALNET offers consultation and turnkey solutions. Just reach out.
