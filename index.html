FAQ

Your questions, answered

Everything you need to know about building your own privacy‑first, open‑source stack.

What exactly does RICALNET provide?

RICALNET offers a public GitHub repository with ready‑to‑use Docker Compose configurations for over 20 privacy‑focused services — all open‑source and self‑hostable. No proprietary lock‑in, no recurring fees.

Is this only for tech‑savvy people?

Not at all. The repo is designed to be accessible to anyone comfortable with the command line. The documentation includes detailed guides, one‑command deployment scripts, and an interactive menu to manage services. For enterprises, RICALNET offers consulting and managed deployment. For homelabbers, it's a practical, educational project.

How do you ensure zero‑trust security?

Every service in the stack is configured to require authentication (via SSO/OIDC/SAML) and encryption (TLS). The architecture advocates network segmentation, strict access controls, and regular updates. The reference architecture includes monitoring and alerting to detect anomalies. You have full control to harden as needed.

How much does it cost to run?

Very little. You pay only for hardware (or VPS), electricity, and bandwidth. Most services can run on a $5–$10/month VPS for personal use, or on a Raspberry Pi at home for near‑zero recurring cost. No per‑user licenses, no data egress fees, no minimum spend.

How do I get started?

Clone the repo, run the setup script, and you're up in minutes. Step‑by‑step guides cover different use cases — from homelab to production. For enterprise/activist deployments, RICALNET offers consultation and turnkey solutions. Just reach out.
