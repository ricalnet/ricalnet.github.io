FAQ

Your questions, answered

Everything you need to know about building your own privacy‑first, open‑source stack.

What exactly does Ricalnet provide?

We offer a public GitHub repository with ready‑to‑use Docker Compose configurations for over 20 privacy‑focused services. Plus, we build and maintain in‑house tools (quantum hasher, IP intelligence, password generator, etc.) — all open‑source and self‑hostable. No proprietary lock‑in, no recurring fees.

Is this only for tech‑savvy people?

Not at all. Our repo is designed to be accessible to anyone comfortable with the command line. We provide detailed documentation, one‑command deployment scripts, and an interactive menu to manage services. For enterprises, we offer consulting and managed deployment. For homelabbers, it's a fun, educational project.

How do you ensure zero‑trust security?

Every service in our stack is configured to require authentication (via SSO/OIDC/SAML) and encryption (TLS). We advocate for network segmentation, strict access controls, and regular updates. Our reference architecture includes monitoring and alerting to detect anomalies. You have full control to harden as needed.

How much does it cost to run?

Very little. You pay only for hardware (or VPS), electricity, and bandwidth. Most services can run on a $5–$10/month VPS for personal use, or on a Raspberry Pi at home for near‑zero recurring cost. No per‑user licenses, no data egress fees, no minimum spend.

How do I get started?

Clone our repo, run the setup script, and you're up in minutes. We provide step‑by‑step guides for different use cases — from homelab to production. For enterprise/activist deployments, we offer consultation and turnkey solutions. Just reach out.
