Features

Backup that's secure by design

Chantik combines authenticated encryption, smart retention, and incremental backups into a single, battle‑tested tool.

ChaCha20‑Poly1305

Authenticated encryption with a 256‑bit key. Your data stays confidential, tamper‑proof, and verifiable — with AES‑256‑CBC fallback for compatibility.

🔑 PBKDF2 · 600,000 iterations

Deduplication

Fixed‑nonce encryption enables safe deduplication via hardlinks. Store identical encrypted blocks once — save storage and bandwidth without compromising security.

🗜️ hardlink · jdupes support

Incremental Backups

Save time and storage. Full backups run on a schedule (e.g., weekly); incremental backups capture only what changed. Restore from any point with ease.

🔄 Full every 7 days · Incremental daily

Smart Retention

Keep what matters. Daily, weekly, and monthly retention policies automatically prune old backups — configurable to match your compliance and storage needs.

📅 Daily=7 · Weekly=4 · Monthly=6

Docker Volume Backup

Seamlessly back up Docker volumes with the same encryption and retention policies. Perfect for containerized services — restore volumes directly from the CLI.

🐳 Volume detection · Direct restore

Real‑time Notifications

Get instant alerts via ntfy.sh. Success, failure, and restore events — with priority levels and tags — so you always know the status of your backups.

🔔 ntfy.sh · Priority levels · Tags

Security

Authenticated encryption you can trust

Chantik doesn't just encrypt — it authenticates. Every backup is verified for integrity and authenticity, so you know your data hasn't been tampered with.

ChaCha20‑Poly1305

Primary cipher with built‑in authentication. Fallback to AES‑256‑CBC when needed.

PBKDF2 Key Derivation

600,000 iterations (configurable) — brute‑force resistant key stretching.

SHA256 Verification

Every encrypted archive includes a checksum. Verification runs automatically on backup and restore.

Fixed Nonce for Deduplication

Deterministic encryption enables safe hardlink deduplication — identical data, identical ciphertext.

Quick Start

Backup in minutes

Clone, configure, and run. Chantik handles the rest — encryption, compression, deduplication, and retention.

1

Clone the repository

git clone https://github.com/ricalnet/chantik.git
2

Generate encryption key

openssl rand -base64 32 > encryption.key
3

Configure & run

cp chantik.conf.example chantik.conf
./chantik.sh
4

Verify your backup

./chantik.sh --verify-all

Full documentation, advanced config, and Docker volume examples at the GitHub repo.

chantik@backup:~$

$ ./chantik.sh
